Use it in Hermes.

Hermes 0.23.0+. Public plugin hooks.
One job, one current JSON, one protected tool.

Open the source on GitHub
git clone https://github.com/blucca/hermes-sourcebind.git
cd hermes-sourcebind
hermes plugins validate "$PWD" --install-deps
hermes plugins install https://github.com/blucca/hermes-sourcebind --no-enable
hermes plugins enable sourcebind

Restart Hermes, then use /sourcebind bind <job> <source.json> [protected_tool]. The default fixture tool is sourcebind_demo_update.
